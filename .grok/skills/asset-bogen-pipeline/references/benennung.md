# Benennung

```
[kategorie]_[unterkategorie]_[motiv]_[BxH]_[nr].png
```

Animationen:

```
[kategorie]_[unterkategorie]_[motiv]_anim_[aktion]_[richtung]_[frame].png
```

## Regeln

- Nur Kleinbuchstaben `a-z`, Ziffern, Unterstrich.
- Keine Leerzeichen.
- Umlaute — `ä=ae`, `ö=oe`, `ü=ue`, `ß=ss`.
- Nummer zweistellig, pro Motiv fortlaufend (`01`, `02`, …).
- Farbvarianten und Zustände ins Motiv: `bett_gruen`, `tuer_offen`.
- Animationen bleiben in ihrer Kategorie. Frame zweistellig, Reihenfolge des Bogens.
- `BxH` ist die Kachelklasse (`1x2`), nicht die Pixelzahl. Pixel stehen nur im Ordnernamen.

## Beispiele

```
figuren_baecker_mann_1x2_01.png
figuren_baecker_mann_anim_gehen_sued_01.png
moebel_betten_bett_gruen_2x2_01.png
boden_gras_kachel_1x1_04.png
bauteile_tueren_tuer_offen_1x2_01.png
ui_buttons_knopf_holz_01.png
```

## Kollisionen

Gleicher Zielname — Nummer erhöhen, nicht überschreiben. In der Kontrolltabelle vermerken.

Namensraum über alle Bögen eines Projekts konsistent halten. Motivnamen nicht zwischen Bögen neu erfinden, wenn dasselbe Ding gemeint ist.
