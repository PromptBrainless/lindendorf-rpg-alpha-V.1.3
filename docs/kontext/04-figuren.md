# Figurenakten

Ordner: `docs/figuren/`. Liste: `docs/figuren/00-index.md`. Eine Datei pro Figur.

Marken, nicht mischen:

- **[Szene]** kann der Held lesen.
- **[Lore]** steht in `lore.ts`.
- **[Wiki]** ist die Figurenkarte und darf weiter gehen als die Szene.
- **[Schriftstück]** ist Papier oder Zeichen.
- **[Bild]** ist eine Datei unter `public`.

Am Ende jeder Datei ein Abgleich.

Offener Programmkonflikt, keine Lore: der Porträtschlüssel `beggar` ist in `stimme.ts` auf den Namen Fenn gelegt. Die Datei heißt `public/art/beggar.jpg`. Fenn ist nicht der Bettler.
Nur das Wiki sagt, der Pfarrer habe das Artefakt selbst in die Grube gelegt. Die Szenen sagen das nicht.
